# Contributing to godot-basics

Use the [latexmk](https://mgeier.github.io/latexmk.html) tool for compilation (see `flappy-bird/.latexmkrc`). This avoids auxiliary files being spewed all over your working directory. Place media files (.png, .jpg, etc.) in a relevant subdirectory of `lfs/tutorials/godot-basics`. Occasionally, a useful generic screenshot may be available in `godot-basics/common/`; name your files meaningfully!

Otherwise, do as you wish. If [typst](https://typst.app/) is your thing, go ahead. Use any document format which appeals to you. Stick to the `lfs/` is binary and `src/` is plaintext rules laid out in the main README.md. If you are unsure, feel free to ask!
